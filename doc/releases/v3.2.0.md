# v_chat_input_ui 3.2.0

Version 3.2.0 adds configurable attachment presentations and recording visuals
without changing the package's default composer behavior.

## Attachment presentations

- Adds typed Media, Camera, Files, Location, and custom attachment actions.
- Adds adaptive action-sheet, modal bottom-sheet, and inline-tray
  presentations.
- Supports grid, horizontal-list, and wrap layouts with consumer-controlled
  action order.
- Adds logical inside, leading, and trailing launcher placement with RTL
  support.
- Coordinates keyboard, emoji, and inline attachment surfaces through one
  composer state model, including system-Back behavior.
- Adds `VMessageInputController` for external keyboard, emoji, attachment, and
  panel-close commands.
- Adds attachment panel theming, localization, semantics, and a custom panel
  builder.

## Composer and recording

- Makes the default Send and Record controls fill the same 48-pixel extent as
  the one-line input container.
- Adds `VInputTheme.composerActionExtent` to customize the shared size.
- Adds `VRecordingState` and `recordingWidgetBuilder` for live custom recording
  visuals while the package continues to own recorder lifecycle, duration
  limits, submission, and cleanup.
- Retains the existing built-in recording widget when no builder is provided.

## Compatibility

- `VAttachmentPresentation.adaptiveActionSheet` remains the default.
- The attachment launcher remains inside the input by default.
- Existing `onAttachIconPress`, `AttachEnumRes`, submission callbacks,
  permissions, picker limits, mentions, reply UI, draft state, and constructor
  defaults remain supported.
- No new dependency is introduced by the 3.2.0 features.

See the [README](../../README.md) for complete attachment and recording
examples.
